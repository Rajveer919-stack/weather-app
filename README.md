# Weather App

Python se bana command-line app jo kisi bhi shehar ka live mausam dikhata hai.

## Features
- Kisi bhi city ka naam daalo
- Temperature, hawa ki speed aur mausam ki halat dekho
- Galat city ya internet na hone par error handle hota hai

## Kaise chalayein
1. Python install hona chahiye
2. Library install karo: `pip install requests`
3. Terminal mein chalao: `python main.py`

## Tech Used
- Python
- requests library
- Open-Meteo API (free, key nahi chahiye)
